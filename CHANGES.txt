0.9.0 --> 0.9.1
- Fixed error "self.read_cards_from_str() does not exist" (wrong function name)
- Fixed error with downloading images for certain cards with the double forward slash "//" in their 
  names resulting to illegal filename. Now the double forward slash can be replaced by a given string

- Improved handling paths for downloading images and creating proxy sheets with "pathlib"
- Spellchecking

0.9.1 --> 0.9.2
- Now using the common 'requests' library
- The 'id' attribute of sets is now correctly retrieved from Scryfall API instead of created randomly
- Updating is now more robust taking into account certain errors that are caused by inconsistencies of the API side.
  There are apparently situations where certain sets might be missing, might have wrong 'card_count' attributes or
  similar things that caused request errors and crashing
- Added more tests
- Added a method to check if the local Scryfall database is consistent. It checks things like all the cards belong in
  a set, no set or the full cards list has duplicate cards, etc.

- The updating methods that fetch only new card info are now deprecated. They raise a warning and just call the full
  update method, so any old code is not broken
- For simplicity, the names of methods 'full_update_from_mtgio' and 'full_update_from_scryfall' have been changed to
  simpler 'mtgio_update' and 'scryfall_update'. Calling the old functions will just raise a warning and call the new
  functions, so any old code is not broken

0.9.2 --> 0.9.3
- Removed the eur, usd and tix fields
- Added prices field which contains eur, usd and tix
- Added multiverse_ids field

0.9.2 --> 0.9.3
- Added the ability to include any card-specific keyword arguments such as lang='en' for reading cards from decklists
  which will only return those matching cards.
- Added the ability to specify the collector number of the card when reading cards from decklists

0.9.4 --> 0.9.5
- Added the 'promo' and 'promo_types' attributes for scryfall cards

0.9.5 --> 0.9.6
- Fixed a Scryfall updating error
- Added a bulk update option for Scryfall
- Added many new attributes for scryfall cards and sets
- Fixed an error with an incorrect warnings.warn parameter when reading
  a decklist from string

 0.9.62 --> 0.9.63
 - Fixed an issue where scryfall_bulk_update fails because of an incorrect attribute name

0.9.6 --> 0.9.7
- Included all the ZODB.FileStorage.FileStorage keyword arguments in MtgDB

0.9.7 --> 0.9.71
- The 'index' and 'pop' methods of PCardList now return correct values

0.9.71 --> 0.9.72
- Added a slight optimization for downloading the images of a PCardList
- Fixed some reduntant namespace logic which caused the app to break with a newer version of setuptools
- Fixed downloads from Scryfall by including appropriate headers for the requests.
  The Scryfall update-methods now accept a User-Agent parameter, which by default is
  the name and the version number of the app.
- 'art_series' cards are now correctly filtered by the normal_playable_cards method of PCardList
- Removed the deprecated Image.ANTIALIAS from image.resize in card proxy images. The default resampling 
  algorithm in Pillow for image resizing is 'bicubic', which should be the best for graphics images
- Added the 'overwrite' parameter to image download methods from scryfall. Setting overwite=False now
  renames duplicate card (name) image files like "Card Name (1).jpg",  "Card Name (2).jpg" etc.

0.9.72 --> 0.9.90
- The app now supports Rulings served by scryfall. Rulings can be updated with the 'scryfall_bulk_update'-method
  by setting 'bulk_type="rulings"'. Rulings are linked to each PCard via the 'rulings' attribute (if the card has 
  any) and PRulings contain a PCardList list of cards they are associated to.
- Added and refined some pretty-printing functions for the Persistent objects (PCard, PCardList, PSet, PRuling, PSetList)
- Added the inbuild __reversed__ method to PCardList and PSetList, which mirrors the same function for general iterables
- Added the 'first' and 'last' attributes to PCardList and PSetList
- Added the 'limit' arg to the where and where_exactly methods of PCardList which limits the amount of results returned 
  by the search
- The unique_cards, pprint and pretty_print_str methods of PCardList now retain the ordering of the cards in the list
- Removed the slow pack-operation from database updates. The pack can be done separately if needed
- Fixed certain methods of PCardList which fail to sort of group a PCardlists that include some special cards
  that have no cmc
- Fixed reading desk strings for the 'deck_str'-method of 'PCardList' which would fail for lines that have the set code
  and the collector number surrounded by the characters '()', which should be allowed
- Fixed errors in generating the json-outputs
- Added the len-property to PCardList and PSetList (a synonym for the inbuilt len())
- Fixed the index-method of PSetList which always returned None
- Changed/Corrected the __sub__ behaviour of PCardList to remove only the given number(s) of card(s) from the list
  instead of all the copies. The copies are removed beginning from the FIRST found occurance in the list. For 
  example, the operation 'four_wild_mongrels - one_wild_mongrel' equals to three_wild_mongrels instead of the 
  old behaviour 'four_wild_mongrels - one_wild_mongrel == empty_pcard_list'

Other changes not related to the functionality
- Added a better system test setup along with a set of more comprehensive tests
- Cleaned up and formatted the repo. Black is the new default formatter.
- Changed the license of the project to MIT, which is more standard for these kinds of projects.
